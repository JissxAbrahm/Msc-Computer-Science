SQL COMMANDS – COMPLETE STUDY NOTE
1. Introduction to SQL
SQL (Structured Query Language) is a standard programming language used to create, manage, manipulate and retrieve data from relational database management systems (RDBMS).

SQL commands are used to:
- Create databases and tables.
- Insert, update and delete records.
- Retrieve information from databases.
- Control user access and permissions.
- Manage database transactions.
SQL commands are classified into five major categories:
1. DDL – Data Definition Language
2. DML – Data Manipulation Language
3. DQL – Data Query Language
4. DCL – Data Control Language
5. TCL – Transaction Control Language

2. DDL – Data Definition Language
DDL commands are used to define, create and modify the structure of database objects such as tables and databases.
Main DDL Commands
Command	Description
CREATE	Creates a database or table
ALTER	Modifies the structure of a table
DROP	Deletes a database or table permanently
TRUNCATE	Removes all records from a table
RENAME	Changes the name of a database object

Syntax and Examples
1. CREATE

Used to create a new database or table.
CREATE DATABASE College;

CREATE TABLE Student (
    id INT,
    name VARCHAR(50),
    age INT
);


2. ALTER

Used to modify the structure of an existing table.
-- Add a new column
ALTER TABLE Student ADD email VARCHAR(100);

-- Modify a column
ALTER TABLE Student MODIFY name VARCHAR(100);

-- Drop a column
ALTER TABLE Student DROP COLUMN email;


3. DROP

Used to permanently delete a table or database.
DROP TABLE Student;

DROP DATABASE College;


4. TRUNCATE

Used to remove all records from a table while retaining its structure.
TRUNCATE TABLE Student;


5. RENAME

Used to change the name of a table.
RENAME TABLE Student TO Students;



3. DML – Data Manipulation Language
DML commands are used to manipulate and modify the data stored inside database tables.
Main DML Commands
Command	Description
INSERT	Adds new records
UPDATE	Modifies existing records
DELETE	Deletes records

Syntax and Examples
1. INSERT

Used to insert new records into a table.
INSERT INTO Student
VALUES (1, 'Jiss', 22);

-- Insert specific columns
INSERT INTO Student (id, name)
VALUES (2, 'Arun');


2. UPDATE

Used to modify existing records.
UPDATE Student
SET age = 23
WHERE id = 1;


3. DELETE

Used to delete records from a table.
DELETE FROM Student
WHERE id = 1;


Note: Without a WHERE condition, UPDATE and DELETE can affect all records in a table.

4. DQL – Data Query Language
DQL commands are used to retrieve or fetch information from database tables.
Main DQL Command
Command	Description
SELECT	Retrieves records from a table

Syntax and Examples
1. SELECT

Used to retrieve data from a table.
-- Display all records
SELECT * FROM Student;

-- Display specific columns
SELECT name, age FROM Student;

-- Retrieve records using condition
SELECT * FROM Student
WHERE age > 20;

-- Sort records
SELECT * FROM Student
ORDER BY age DESC;


Important SELECT Clauses
Clause	Description
WHERE	Filters records based on conditions
ORDER BY	Sorts records in ascending or descending order
GROUP BY	Groups records with similar values
HAVING	Filters grouped records
DISTINCT	Removes duplicate values
LIMIT	Restricts the number of returned rows

Example
SELECT age, COUNT(*)
FROM Student
GROUP BY age
HAVING COUNT(*) > 1;


This query displays age groups containing more than one student.

5. DCL – Data Control Language
DCL commands are used to control database access and permissions for users.
Main DCL Commands
Command	Description
GRANT	Provides privileges to users
REVOKE	Removes privileges from users

Syntax and Examples
1. GRANT

Used to provide permissions to a database user.
GRANT SELECT, INSERT
ON College.Student
TO user1;


2. REVOKE

Used to remove previously granted permissions.
REVOKE INSERT
ON College.Student
FROM user1;



6. TCL – Transaction Control Language
TCL commands are used to manage database transactions.

A transaction is a group of SQL operations treated as a single logical unit of work.
Main TCL Commands
Command	Description
COMMIT	Permanently saves transaction changes
ROLLBACK	Undoes uncommitted changes
SAVEPOINT	Creates a temporary rollback point
SET TRANSACTION	Sets transaction properties

Syntax and Examples
1. COMMIT

Used to permanently save changes made during a transaction.
START TRANSACTION;

INSERT INTO Student
VALUES (3, 'Anu', 21);

COMMIT;


2. ROLLBACK

Used to undo changes made during a transaction that have not been committed.
START TRANSACTION;

DELETE FROM Student
WHERE id = 3;

ROLLBACK;


3. SAVEPOINT

Used to create a point within a transaction to which we can roll back.
START TRANSACTION;

INSERT INTO Student
VALUES (4, 'John', 22);

SAVEPOINT S1;

INSERT INTO Student
VALUES (5, 'Alan', 23);

ROLLBACK TO S1;

COMMIT;


Here, the second INSERT operation is undone, while the first INSERT operation is retained and committed.

4. SET TRANSACTION

Used to set transaction properties.
SET TRANSACTION
ISOLATION LEVEL SERIALIZABLE;



7. Differences Between Important SQL Commands
DELETE vs TRUNCATE vs DROP
DELETE	TRUNCATE	DROP
Deletes selected records	Deletes all records	Deletes the entire table
Supports WHERE	Does not support WHERE	Does not support WHERE
Table structure remains	Table structure remains	Table structure is removed
DML	DDL	DDL
Can be rolled back within a supported transaction	Transactional behaviour depends on DBMS	Transactional behaviour depends on DBMS

DDL vs DML
DDL	DML
Data Definition Language	Data Manipulation Language
Deals with database structure	Deals with table data
CREATE, ALTER, DROP	INSERT, UPDATE, DELETE
Used to define objects	Used to manipulate records

COMMIT vs ROLLBACK
COMMIT	ROLLBACK
Saves changes permanently	Undoes uncommitted changes
Confirms a transaction	Cancels transaction changes
Changes cannot normally be undone using ROLLBACK afterward	Restores the previous transaction state
